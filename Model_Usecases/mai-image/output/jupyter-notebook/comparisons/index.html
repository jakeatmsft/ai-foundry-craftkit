Product photography

Prompt: Create a premium photorealistic studio product photograph for the fictional ORBIT brand. One matte terracotta ceramic mug with a single curved handle on its right, sitting on a pale stone plinth. The word ORBIT is printed clearly on the front in small ivory uppercase letters. Soft morning light from the upper left, believable contact shadow, fine ceramic texture, warm cream seamless background. Three-quarter camera view. Keep the entire mug visible with generous negative space. No additional objects or text.

GPT uses its labeled quality and size; MAI uses default quality with no background parameter. Dimensions are the returned PNG size. MAI transparent-background requests are prompt-only.

Generation payload differences

GPT generation payload

{
  "model": "gpt-image-2",
  "prompt": "A terracotta ORBIT mug",
  "n": 1,
  "size": "1024x1024",
  "quality": "low",
  "output_format": "png",
  "background": "auto"
}

MAI generation payload

{
  "model": "MAI-Image-2.6",
  "prompt": "A terracotta ORBIT mug",
  "width": 1024,
  "height": 1024,
  "auto_aspect_ratio": false,
  "web_grounding": false
}

GPT specifies size, quality, output format, and background. MAI specifies width and height, with automatic aspect-ratio selection and web grounding disabled here. For MAI-Image-2.6-Flash, change the model value to MAI-Image-2.6-Flash. These examples use the same abbreviated prompt.
